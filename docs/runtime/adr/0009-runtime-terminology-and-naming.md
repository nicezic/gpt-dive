# ADR 0009 — Runtime Terminology and Naming

> `/grill-with-docs` 수준의 runtime 전체 용어 정리를 ADR 0005 구현에서 분리하기 위한 placeholder. **아직 결정하지 않았다.**

ADR 0005 구현에서 직접 수정되는 이름은 일관되게 리팩토링할 수 있지만, Execution / Task / Worker / result / output / console 등 repo-wide vocabulary 정리는 별도 작업으로 다룬다.

이 ADR은 실제 용어 조사와 충돌 분석 후 canonical vocabulary를 결정한다. 미리 이름을 확정하지 않는다.
